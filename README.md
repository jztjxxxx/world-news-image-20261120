One image that sums up the world news of Friday 20 November 2026, drawn as a one-page newspaper poster: the Wall Street rout (S&P 500 −3.7%, Nasdaq negative for the year), the SEC's accounting probe into Nvidia, Bitcoin crashing below $60,000, Russia's 100-missile strike on Kyiv and a missile crashing in Poland, Denmark accusing Russia of plotting to kill a Ukrainian rapper, an Anthropic mathematician's claim that Claude proved the Riemann Hypothesis, GTA VI making $3.79bn in a single day, the UK–EU reset deal, COP31 going into overtime, and the US Senate passing the DEATH BETS Act — 46 stories in all, 15 with original flat illustrations and numbered pins on a world map, plus 31 numbered briefs and a date-check box that names the older news deliberately left out. The poster is drawn in `poster.html` (HTML/CSS with inline SVG) and rendered to `entry.png` by `render.mjs`; the entry program `main.ts` verifies the PNG and copies it to `/output/entry.png`, byte for byte, every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Re-render the poster

```sh
node render.mjs
```
